# study-sprint-coach

A specially-designed skill for learning in limited time.

这是一个面向限时学习的证据驱动冲刺教练 Skill：把课程资料、诊断结果和每日可用时间，转成可执行计划、短测与复盘闭环。

- Skill 包：[study-sprint-coach](study-sprint-coach/README.md)
- 提交材料：[submission/checklist.md](submission/checklist.md)
- 技术文章草稿：[submission/technical-article-draft.md](submission/technical-article-draft.md)
- 本地运行：`python study-sprint-coach/scripts/study_sprint.py --help`

适用场景包括期末冲刺、认证考试、入职培训、项目补课和演讲准备。工具只依据用户当前提供的材料与状态文件作答；材料未提取或缺少定位时，会显式降级为临时计划。
