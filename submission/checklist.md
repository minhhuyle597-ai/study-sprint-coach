# Production AI Skills 大赛提交清单

## 推荐表单文案

- 作品名称（10–30 字）：`证据驱动的学习冲刺教练`
- 作品简介（200–300 字）：

> Study Sprint Coach 是面向大学期末复习的本地优先 Agent Skill。它读取课程材料、截止日期、每日时间和诊断结果，为每个主题保留页码、幻灯片、标题或题号定位，按相关度、掌握度、得分增益与时间成本生成不过载计划，并将排不下的内容列入积压。学习者完成测验后，工具把结果写入 JSON 状态，更新掌握度并重排后续任务。项目仅依赖 Python 标准库，提供原子写入、输入校验、合成微积分演示、固定输出合约、行为基线和单元测试。OpenVINO 探测如实报告本机环境；当前未安装运行时，因此不声称 GPU、NPU 加速或未测量的性能提升。材料默认留在本机，云上传需明确授权，也不用于正在进行或受监考的考试。
